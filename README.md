Product List Android App

Description
This Android application displays a list of products using a RecyclerView. When a user selects a product, the app navigates to a detail screen and shows the product’s name, price, and description.

Features
- Displays products in a RecyclerView
- Handles item click events
- Navigates between activities using Intent
- Passes data between activities
- Displays product details on a separate screen

Technologies Used
- Kotlin
- Android SDK
- RecyclerView
- XML Layouts (ConstraintLayout / LinearLayout)

Project Structure
- MainActivity: Displays list of products
- DetailActivity: Displays selected product details
- ProductAdapter: Binds product data to RecyclerView
- Product: Data class for product information

How to Run
1. Open the project in Android Studio
2. Sync Gradle files
3. Build and run the application on an emulator or device
